# 季长青

- 性别：男
- 年龄：67
- 角色功能：考功院审核者 / 阶段性导师 / 制度公信力代表
- 身份：青衡宗外门考功长老
- 修为：筑基中期
- 与主角关系：先审核、后观察，再逐步认可
- 核心特质：刻板、重证据、不爱押宝天才
- 标志性特征：核对任何事前先把原始记录拿到手，不听二手转述。
- 动机：维持外门考功体系的可信度。对他而言，规则失真比某个弟子吃亏更危险。
- 第一卷功能：主持林砚的修为复核；在周恪事件中只处理证据能证明的部分；外门小考后给林砚内门候补观察资格。
- 关系走向：不是“慧眼识珠后一味护主角”，而是每次只给与林砚当前表现相匹配的机会。
- 使用边界：不替林砚查案，不赠送高阶资源，不以一句“此子不凡”跳过资格流程。
