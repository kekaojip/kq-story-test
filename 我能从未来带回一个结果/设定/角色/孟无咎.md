# 孟无咎

- 性别：男
- 年龄：20
- 角色功能：长期竞争者 / 正统修炼路线镜像
- 身份：青衡宗外门弟子
- 修为：炼气五层
- 与主角关系：竞争对手，非恶意反派
- 核心特质：直接、自律、骄傲但认结果
- 标志性特征：练剑前一定把袖口束紧，打完后无论输赢都先复盘自己哪一步慢了。
- 核心目标：凭正面实力进入内门，不靠家世与关系。
- 第一卷功能：给林砚一个不能靠信息差永远绕开的“硬实力标尺”；最先察觉林砚的可怕之处在于总能在关键节点选对，而不是单纯境界暴涨。
- 关系走向：竞争 → 认可 → 某些任务中阶段性合作 → 长期各走不同修行路线。
- 使用边界：不为了衬主角把孟无咎写成嘴硬降智；他可以输，但必须输在林砚真实的选择、准备或技艺上。
