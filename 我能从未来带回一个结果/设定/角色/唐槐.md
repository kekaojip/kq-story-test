# 唐槐

- 性别：男
- 年龄：21
- 角色功能：同门朋友 / 籍录房内部信息接口 / 主角的人情锚点
- 与主角关系：同住同事，关系不错但都懂底层弟子没有资格随便替人扛事。
- 修为：炼气三层
- 核心特质：嘴碎、实际、怕麻烦但心不坏
- 标志性特征：总把能换钱的废纸、旧竹简边角收起来；说话喜欢先报价格。
- 当前目标：攒够贡献转去任务堂，摆脱籍录房的死工资。
- 第一卷功能：提醒林砚矿役名单时间不对；提供正常流程参照；在周恪事件里证明主角并非凭空猜中。
- 退场规划：第一卷后仍可偶尔出现，但不跟随主角进入所有高阶地图；后期可成为青衡宗基层执事，作为旧地图稳定关系点。
- 使用边界：不让唐槐替林砚拿核心证据、做最终举报或完成关键清算。
