# 题材正文提示卡

## 题材边界
玄幻脑洞为主，东方仙侠为辅。核心不是“系统播报未来”，而是修仙秩序被“未来结果先落到现实”撬动。仙侠感来自宗门规矩、资源、身份、功法与人情，不靠空泛古风词。

## 核心逻辑
- 每轮剧情先有现实压力或机会，再由问果提供一条未来分支。
- 推演必须产生真正的选择题：同一条未来里通常存在多个值得带回的结果，只能取一个。
- 选择结果后，要尽快在现实里看到该结果如何改变修为、资格、资源、关系或局势。
- “模拟”只负责制造更高杠杆的选择，真正推进现实剧情的人始终是林砚。

## 读者期待
1. 这次未来会发生什么？
2. 未来里最值钱的结果是哪一个？
3. 林砚会不会选一个表面价值低、实际杠杆更高的结果？
4. 结果落到现实后，原有规则和别人的判断会怎样被改写？
5. 新现实又会生成什么更危险、更值钱的命岔？

## 核心爽点 / 情绪
- 困局明确 → 未来先跑一次 → 找到突破口 → 只取一果 → 现实立刻见效。
- 公开反差要建立在别人原本合理的判断上，不靠全员降智震惊。
- 小爽：结果第一次生效、信息差抢先一步。
- 中爽：资源/资格/境界到账，制度对主角重新定价。
- 大爽：主角选择一个别人看不懂的低表面价值结果，最终撬出远高于常规选择的收益。

## 正文落点
- 场景优先落在名册、任务回执、灵石、丹药、功法玉简、测灵石、矿役调令、擂台、洞府等可见物件上。
- 系统/问果提示要短，承担规则和关键结果，不替代叙事。
- 修炼写瓶颈、验证和结果，不写长段打坐说明。
- 宗门制度只写当前冲突需要的那一层，避免一次性解释完整体系。

## 前中后期打法
- 前期：反复证明“结果型模拟”与普通预知不同，至少交付修为、记忆/技艺、资源/资格三类玩法；把林砚从可被随手分配的低层弟子抬到有选择权的位置。
- 中期：结果选择开始出现真正机会成本。带修为就放弃关键证据，带身份就放弃稀有资源，带资源就可能失去一段未来真相。
- 后期：名位、因果与界域级结果开放，冲突从个人逆袭升级到“谁能定义现实已经发生了什么”。

## 节奏密度
番茄男频快节奏。每章至少推进“现实局势 / 问果玩法 / 修炼资源 / 身份认知”之一；连续纯解释不得超过一个短场景。推演不是独立小故事，必须与当前现实任务形成闭环。

## 场景颗粒
优先使用：外门籍录房、矿役名册、测灵石、功法阁、任务堂、丹房、演武场、灵药谷、洞府名额、宗门榜单、贡献点、灵石价格、执事权限。

## 禁止漂移
- 不写成无脑模拟日志。
- 不靠“无限重开”枚举最优解。
- 不让系统替主角判断该选什么。
- 不给带回结果附加临时编造的根基暗伤来硬压爽点。
- 不用全员震惊替代真实收益。
- 不把修仙资源链、身份差距和现实敌人写丢。
- 不提前开放名位、因果、界域级结果。

## 卡片置信度
- 主题材：玄幻脑洞，高置信。
- 辅题材：东方仙侠，中置信，仅吸收“修行规矩 + 身份约束 + 资源选择”的部分。
- 当前无外部对标书，正文以本书细纲、题材定位和文风为最高项目级约束。
