# 大纲

## 全书体量与阶段总览

- 全书总章节数：约 400 章
- 目标字数：约 120 万字
- 单章目标：约 2800-3300 visible_chars_v1
- 全书情绪曲线：被安排的窒息感 → 掌握选择后的连续反转与爽感 → 选择代价与更大命运秩序冲突 → 从“偷一个未来结果”走到“定义未来如何成立”

### 阶段划分
1. **开篇期（第1-50章）**：建立林砚、青衡宗底层资源逻辑、问果第一层与核心爽点循环；阶段末林砚进入内门候补，读者确认“选择结果”比“看未来”更重要。
2. **发展期（第51-280章）**：筑基至元婴，地图从青衡宗扩到临川域、跨域道统；结果权限从“自身状态”升级到“持有物、名位”，同时出现能够察觉未来异常的人。
3. **高潮期（第281-370章）**：化神至炼虚，司命一脉正式入场，林砚开始接触因果之果；未来不再只是工具，而成为双方争夺的秩序权柄。
4. **收尾期（第371-400章）**：合道/渡劫，界域之果开放，完整揭示问果与可能未来真相，解决“唯一正史”与自由选择冲突。

### 各阶段节奏公式
- 开篇期：具体生存压力 → 一次未来分支 → 选一果 → 现实立刻见效 → 身份/资源重新定价 → 新命岔。
- 发展期：更高价值目标 → 多个都值得带回的结果产生机会成本 → 现实势力争夺 → 地图/身份升级 → 未来异常逐渐可见。
- 高潮期：未来与现实互相反制 → 对手能制造“假定局/锁未来” → 林砚必须在无法枚举答案时主动下注 → 因果级结果兑现。
- 收尾期：终极真相回收 → 林砚不再只选择个人收益，而要选择苍梧界未来的成立方式 → 终局大果只能靠主角亲手完成对应因果。

### 关键节点与钩子链
- 第1章：第一次看到自己九十日内死亡，并带回“炼气四层”。
- 第6章：第一次亲手推翻未来确认结局，完成问果闭环并获得新命数。
- 第18章：外门小考首个大兑现，证明选择技艺结果可以胜过单纯堆修为。
- 第50章：进入内门候补，命籍玉牌出现无法稳定记录的异常。
- 第100章：筑基并开放“持有之果”。
- 第150章：第一次明确发现有人对被改写的未来留下残余感知。
- 第200章：金丹，开放“名位之果”。
- 第280章：跨域大战结束，主角成为影响一域的核心变量。
- 第300章：司命一脉正式锁定林砚，开放因果之果前置。
- 第350章：问果真实来源被完整揭示。
- 第380章：开放界域之果，终局选择开始。
- 第400章：未来不再由“唯一正史”预先决定，主角完成自身与世界的选择权闭环。

## 卷级大纲

### 第一卷：名单之外（第1-50章，约15万字）
林砚在矿役名单上看见自己的名字，问果第一次开启。他从九十日未来中带回炼气四层，先把自己从死亡岗位里硬生生拿出去，再查清名单寻租、参加外门小考、进入灵药谷任务，逐步把“未来结果”从保命工具用成资源和身份杠杆。卷末获得内门候补资格，但命籍玉牌出现无法稳定记录其命线的微小异常。

### 第二卷：筑基以前，先拿到未来的东西（第51-100章，约15万字）
进入内门竞争与临川仙城。林砚需要在筑基名额、洞府、丹药与任务资格之间做真正取舍；问果第二层“持有之果”开放，第一次把未来实际拿到手的物品带回现实。卷末筑基，并发现问果对“所有权”有比宗门契约更古老的判定方式。

### 第三卷：有人记得被删掉的明天（第101-150章，约15万字）
紫府路线开启，临川域诸宗秘境并行。林砚连续改写多条未来后，第一次遇到对“已经没有发生的事”保留模糊记忆的人。主线从单纯升级增加“未来残痕”谜团，但不完整揭示司命体系。

### 第四卷：我把未来的身份带了回来（第151-200章，约15万字）
金丹争道、宗门权力与域级资格成为主要矛盾。问果第三层“名位之果”开放，林砚第一次直接带回未来中已经取得的公开资格/名位，令现有秩序不得不重新解释他。卷末正式成为临川域有名有姓的人物。

### 第五卷：一域之局（第201-250章，约15万字）
元婴阶段，跨域道统与战争线展开。主角不能再只为自己挑果，因为一项选择会改变宗门、旧友和一城修士的生死。问果的“因果参与要求”开始卡住他，逼他亲自成为大事件的核心因。

### 第六卷：观命者（第251-300章，约15万字）
化神阶段，维护命运记录的古老体系浮出水面。对方第一次能针对问果设计“锁死未来”的局。林砚逐步接触第四层“因果之果”，但只有真正建立的债、盟约和归属才能带回。

### 第七卷：没有发生过的世界（第301-350章，约15万字）
炼虚阶段，进入天外古道统与可能世界遗迹。完整确认问果并非单纯预知，而是在真实可能未来中抽取已成之果；司命一脉的“唯一正史”目标与林砚彻底对立。太一命君正面锁定主角。

### 第八卷：今日为果（第351-400章，约15万字）
合道至渡劫。第五层“界域之果”开放，但终局结果必须由林砚本人承担足够因果才能选择。最终矛盾不是“谁更会算未来”，而是谁有资格让某个未来成为唯一现实。林砚完成从被一张名单安排命运，到为苍梧界保留选择可能的闭环。
