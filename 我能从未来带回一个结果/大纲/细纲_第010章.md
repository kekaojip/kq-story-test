# 细纲（第10章）

### 第十章：第一场，我走折风道
- 核心事件：外门季度小考正式开始，林砚在第一项技艺测试中主动选择高分但容错更低的“折风道”，用刚带回的小成身法把有限灵力转成排名优势。
- 字数目标：3100字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期第10章；首批细纲停靠章，U02进入正式竞争。
- 单元ID/位置：U02，第4拍“把结果价值变成分数”。
- 目标情绪：正式开考的紧张 → 别人按境界选择稳妥路线 → 林砚根据自身真正优势主动选高分路线 → 第一段成绩落地。
- 主角目标/关键选择：不跟炼气五层弟子硬拼灵力总量，主动走最匹配《折风步》短爆发优势的高分路线。
- 章节定位：高压 / 公开竞争。
- 本章结构公式：小考规则落地 + 路线选择 + 折风步实战化 + 初步排名。
- 章首钩子：考功院把三条试道同时亮出来，最右侧那条只有一句提示——“失误一次，本项作废。”
- 爽点：林砚不是靠境界碾压，而是把未来练成的技艺精准投到高权重测试上；第一场结束后，他以炼气四层进入第一梯队。
- 本章标价：稳妥路线保底但分数上限低；折风道高风险高上限，失败本项作废。林砚前一章已实测连续使用边界，因此选择不是莽。
- 闭环状态：完成“未来技艺 → 现实验证 → 正式分数收益”；U02主线继续，尚未完成小考前十总闭环。
- 本章禁止提前释放：不让林砚直接拿总排名第一；不打正式擂台决赛；不再次问果；不让孟无咎输给林砚；不写小考完整结束。
- 写手自由区：三条试道的具体机关形式、林砚每次折风换位的视觉落点、其他弟子的有限旁观反应。
- 契约风险：契约安全。主角凭已验证信息主动选择高分路线，收益归主角。

#### 内容概括（五段式）
- 起因：外门季度小考开场，第一项技艺测试允许弟子在三种难度路线中自选，难度越高分值上限越高。
- 发展：多数炼气四层弟子选中档，五层以上才有人尝试高档。林砚先看完整规则与前几名表现，确认高档“折风道”主要考短距离换位、节奏和落点，不考持续灵力。
- 转折：孟无咎选高档并稳定通过，给林砚一个真实标尺；轮到林砚时，负责登记的弟子提醒他四层修为失败率很高。
- 高潮：林砚仍选择折风道，以小成身法和前一日测出的灵力分配通过关键节点；最后一段灵力已明显下降，但他没有多用一步，压线完成。
- 结尾：第一项成绩公布，林砚进入本项第一梯队。孟无咎看完只说一句：“原来你圈的是技艺。”

#### 情节安排（多线）
- 主线推进：L01身份竞争正式进入可量化排名。
- 辅线推进：L02技艺结果完成公开价值兑现；L04孟无咎与林砚进入真正竞争态。
- 事件线 / 任务线：季度小考第一项完成，后续仍有修为复核与实战排位。
- 任务卡点：四层总灵力不占优 → 高分路线却偏短爆发 → 林砚用身法完成场景匹配。
- 感情线 / 关系线：孟无咎确认林砚此前“圈技艺”并非虚张声势，竞争关系更具体。
- 逻辑线：技能边界已实测 → 看试道要求 → 匹配优势 → 主动选高档 → 取得高分 → 打开前十可能性。

#### 人物关系和出场顺序
- 出场顺序：林砚 → 季长青（主持背景）→ 孟无咎 → 若干一次性考生/登记弟子。
- 镜头准入：季长青不额外关照；孟无咎先完成自己的测试，不给主角当陪衬；一次性考生只提供难度参照。
- 人物关系变化：林砚/孟无咎从“互相观察”进入明确的同场竞争。
- 视角/信息差：场外人知道林砚身法完成度高但不知道来源；读者知道这是他放弃炼气五层换来的结果。
- 信息差触发点：登记弟子按四层修为预测他会选中档，林砚的选择推翻合理预期。
