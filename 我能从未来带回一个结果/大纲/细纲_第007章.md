# 细纲（第7章）

### 第七章：四层，只够报名
- 核心事件：林砚报名外门季度小考，第一次正面看到自己与真正准备型弟子的差距；孟无咎登场，林砚确认单靠突然得到的炼气四层不够进前十。
- 字数目标：2900字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期第7章；U02起步，换压力线。
- 单元ID/位置：U02｜外门小考，第1拍“资格有了，实力还不够”。
- 目标情绪：上一单元胜利后的短松弛 → 新标尺出现 → 不服输但不盲冲的期待。
- 主角目标/关键选择：报名并弄清小考评分结构，先找“最短板”而不是急着再涨境界。
- 章节定位：推进 / 新单元立标尺。
- 本章结构公式：报名 + 规则拆分 + 孟无咎亮相 + 找到短板。
- 章首钩子：唐槐说得很直：“四层能把你从矿里捞出来，但进前十？只够交报名牌。”
- 爽点：不是立刻打脸，而是林砚快速拆出小考真正评分权重，发现自己最缺的不是修为，而是技艺完成度。
- 本章标价：前十=20-60贡献区间 + 功法/丹药奖励；《折风步》借阅需20贡献，而林砚只有4点。
- 闭环状态：建立U02目标与资源缺口，第三次问果条件成熟但不在本章启动。
- 本章禁止提前释放：不让林砚直接得到《折风步》；不让孟无咎主动挑衅；不写第三次推演；不让季长青给特殊照顾。
- 写手自由区：报名现场、弟子对小考各部分的议论、孟无咎第一次出场的动作和短对话。
- 契约风险：契约安全。主角主动拆规则，竞争者不降智。

#### 内容概括（五段式）
- 起因：季度小考报名开启，林砚决定参加。
- 发展：他拿到评分说明：修为复核、技艺测试、实战排位三部分，单靠炼气四层只能保证不被第一轮刷掉。
- 转折：林砚发现自己4点贡献连一门像样的身法借阅都不够，而多数前十热门弟子至少准备了两三个月。
- 高潮：孟无咎在报名后的公开试桩区完成一轮稳定表现，林砚第一次看到“正统积累”的硬标尺；孟无咎没有嘲讽，只看了林砚新登记的四层修为一眼。
- 结尾：林砚把评分表折起来，圈出的不是“修为”，而是“技艺”。

#### 情节安排（多线）
- 主线推进：L01 从保住身份转为主动争取更高身份。
- 辅线推进：L02功法/贡献资源缺口建立；L04孟无咎竞争线正式启动。
- 事件线 / 任务线：报名期3日，小考10日后开始。
- 任务卡点：四层达标 → 贡献不足 → 无法正常在短期内补齐技艺 → 需要新的高杠杆选择。
- 感情线 / 关系线：孟无咎与林砚互相第一次估价，无敌意。
- 逻辑线：报名 → 看评分结构 → 找短板 → 看到标杆 → 决定下一次问果围绕技艺价值。

#### 人物关系和出场顺序
- 出场顺序：林砚 → 唐槐 → 报名弟子群像（背景）→ 孟无咎。
- 镜头准入：孟无咎只需一个稳定试桩和一句实际对话，不能靠旁人吹十段。
- 人物关系变化：林砚/孟无咎从陌生变成互相记住名字的竞争者。
- 视角/信息差：其他人只知道林砚异常突破四层，不知道他还有问果。
- 信息差触发点：有人判断林砚“境界够、技艺来不及补”，这个判断在当前信息下合理。
