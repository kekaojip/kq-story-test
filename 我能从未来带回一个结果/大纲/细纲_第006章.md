# 细纲（第6章）

### 第六章：这张名单，到你为止
- 核心事件：林砚把可验证证据链交给季长青，周恪的籍录权限被剥离并进入追责；U01完整收束，外门季度小考报名窗口随之打开。
- 字数目标：3100字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期第6章；第一剧情单元清算与第二单元入口。
- 单元ID/位置：U01，第6拍“清算/余波/新门”。
- 目标情绪：证据是否够用的紧张 → 规则反过来压住操弄规则的人 → 干净清算后的轻快 → 新机会抬头。
- 主角目标/关键选择：只提交能证实的事实，不扩大指控；确保自己和唐槐不会因“擅取档案”被反咬。
- 章节定位：清算 / 关系回收 / 新钩子。
- 本章结构公式：交证据 + 三方核对 + 权限剥离 + 新机会。
- 章首钩子：季长青没有先看私账，而是先问：“你从哪里拿到的？”
- 爽点：周恪最常用的“按规矩办”最终成为清算他的方式；林砚没有越权，证据来源、正式回执与私账相互闭合。
- 本章标价：林砚保住籍录岗位与正常月例，矿役后患解除；周恪失去可用于寻租的执行权限。
- 闭环状态：U01全闭环；问果第二次现实改写结算出新命数，进入U02。
- 本章禁止提前释放：不把周恪处死/废修为；不牵出宗门大阴谋；不让季长青收徒；不直接开始第三次问果。
- 写手自由区：证据核验的问答、周恪在被要求交印时的反应、清算后籍录房的轻微气氛变化。
- 契约风险：契约安全。清算由林砚取证和选择触发，季长青只执行其职责范围。

#### 内容概括（五段式）
- 起因：林砚把档袋交给季长青，先说明所有材料取得路径。
- 发展：季长青调取正式原档，让周恪到场逐项解释。周恪能解释单个流程，却无法解释私账金额、调令编号和提前顺位三者同时吻合。
- 转折：调查范围从“林砚是否篡改名册”变成“周恪是否利用籍录权限出售顺位”。
- 高潮：季长青收走周恪的籍录印和当前调令权限，将其移交外门执法处继续追责；本章只写已确定处分，不预判后续刑罚。
- 结尾：林砚回到住舍，问果结算第二项已确认坏结局被推翻，命数+1；同一时间，唐槐把刚贴出的季度小考报名告示拍到他桌上。

#### 情节安排（多线）
- 主线推进：L01 从单纯脱险变成获得新的向上入口。
- 辅线推进：L03正式收束；L02开启季度小考资源线；L04通过报名名单预告孟无咎。
- 事件线 / 任务线：外门季度小考报名开启三日。
- 任务卡点：证据是否合规 → 核对来源 → 周恪无法自洽 → 权限剥离。
- 感情线 / 关系线：季长青对林砚建立“知道怎么把事做成证据”的第一层认可；唐槐关系轻微升温。
- 逻辑线：未来记忆选对 → 现实证据链闭合 → 清算 → 新坏未来被推翻 → 命数补充 → 新目标出现。

#### 人物关系和出场顺序
- 出场顺序：林砚 → 季长青 → 周恪 → 唐槐。
- 镜头准入：周恪允许为自己辩解；季长青只判能证实的责任；唐槐只在尾声承接气氛与新告示。
- 人物关系变化：林砚/周恪核心对抗结束；林砚/季长青由审核关系转为有限认可。
- 视角/信息差：读者和林砚知道证据来自未来记忆；季长青只看现实证据，仍能得出成立结论。
- 信息差触发点：季长青评价“你像是提前知道该找什么”，林砚不解释。
