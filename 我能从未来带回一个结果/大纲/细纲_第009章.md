# 细纲（第9章）

### 第九章：你练了多久？
- 核心事件：林砚在现实训练场验证《折风步》小成，确认技艺结果完整成立但仍受当前炼气四层灵力上限约束；孟无咎亲眼看到后第一次重新估价他。
- 字数目标：2900字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期第9章；第三次结果现实验证。
- 单元ID/位置：U02，第3拍“技艺结果变成公开能力”。
- 目标情绪：想看外挂到底有没有用 → 技艺丝滑落地 → 发现并非无脑万能 → 对小考更有把握。
- 主角目标/关键选择：测试折风步在当前修为下的真实连续使用次数、转向极限和与基础剑式的配合，不为了炫技把灵力耗空。
- 章节定位：修炼试错 / 关系推进。
- 本章结构公式：单人实测 + 发现边界 + 与剑式配合 + 孟无咎观察。
- 章首钩子：林砚不用回忆步法怎么走，他的身体已经先走对了。
- 爽点：小成级折风步直接落地，省掉数十日练习时间；孟无咎从“临时突破的四层”改判为“有真东西的竞争者”。
- 本章标价：折风步小成提高的是技艺与实战两项，但四层灵力只够高强度连续施展有限次数，必须把每次位移用在真正换分的位置。
- 闭环状态：第三次结果验证完成；小考正式开场留第10章。
- 本章禁止提前释放：不让林砚再突破五层；不让孟无咎认输或奉承；不提前打正式排位；不新增问果使用。
- 写手自由区：训练场障碍物、折风步具体视觉感、林砚如何测试连续次数、与《截雨剑式》的一个简单组合。
- 契约风险：契约安全。能力有可见收益，也有来自既有修为体系的自然边界，不是临时反噬。

#### 内容概括（五段式）
- 起因：林砚在空闲训练场第一次现实使用折风步。
- 发展：动作和节奏几乎不需要思考，但灵力消耗仍按炼气四层计算；他逐次测出自己能稳定连续使用的范围。
- 转折：林砚发现小考不需要长距离奔袭，折风步的短换位恰好适合技艺桩和擂台，因此当前限制并不伤核心价值。
- 高潮：他把折风步与《截雨剑式》基础封线配合，完成一次比自身境界常规水平更干净的试桩；恰好被同场的孟无咎看见。
- 结尾：孟无咎问“这门身法你练了多久？”林砚看了眼自己的手：“比你想的久。”不解释未来。

#### 情节安排（多线）
- 主线推进：L01问果技艺结果被现实证明。
- 辅线推进：L02折风步成为当前核心技艺资产；L04孟无咎关系从观察进入正式竞争。
- 事件线 / 任务线：小考次日开场。
- 任务卡点：技艺小成 ≠ 无限灵力 → 需要测使用边界 → 找到适合小考的用法。
- 感情线 / 关系线：孟无咎认可林砚“值得认真看”，但没有友谊跃迁。
- 逻辑线：结果落地 → 现实身体会用 → 修为限制连续施展 → 场景需求刚好匹配短爆发 → 战术可执行。

#### 人物关系和出场顺序
- 出场顺序：林砚 → 少量训练弟子（背景）→ 孟无咎。
- 镜头准入：孟无咎只在后半段进入，争的是“你到底是什么水平”，不争口舌。
- 人物关系变化：孟无咎对林砚从“异常突破者”调整为“需要认真准备的对手”。
- 视角/信息差：孟无咎不知道技艺来自未来；林砚知道自己的准备时间实际上来自推演。
- 信息差触发点：孟无咎问训练时长，提醒读者这种完成度在正常时间尺度下不合理。
