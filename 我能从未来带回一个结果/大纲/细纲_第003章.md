### 第三章：名单上少了一个人
- 核心事件：季长青主持修为复核，林砚的炼气四层得到宗门正式记录，矿役名单依法撤名；问果结算“已改写确认结局”，生成新命岔与命数。
- 字数目标：3000字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期第3章；黄金三章完成第一次完整兑现。
- 单元ID/位置：U01，第3拍“第一次现实改命闭环”。
- 目标情绪：悬着的结果能否被承认 → 公开硬验证 → 名字被划掉的释放感 → 新玩法再次拉起期待。
- 主角目标/关键选择：只证明自己符合免矿役条款，不借机夸大周恪问题；先拿下确定收益。
- 章节定位：高压 / 第一次公开兑现。
- 本章结构公式：测灵石复核 + 程序确认 + 撤名 + 命岔结算。
- 章首钩子：季长青把矿役名单压在测灵石旁，先问林砚一句：“你要复核的是修为，还是名单？”
- 爽点：测灵石稳定显示炼气四层，季长青当场按条款划去林砚名字。
- 本章标价：三日矿役生效倒计时终止；四层资格获得制度承认。
- 闭环状态：第一轮完成“未来结果 → 现实验证 → 旧结局被推翻 → 获得新命数”。
- 本章禁止提前释放：不处理周恪最终责任；不揭第二次未来细节；不把季长青写成主角靠山；不出现内门高层。
- 写手自由区：考功院测灵石仪式、旁观弟子的有限反应、季长青核对记录的细节。
- 契约风险：契约安全。主角选择先兑现自己资格，清算后移有明确新债。

#### 内容概括（五段式）
- 起因：林砚被带到考功院做即时修为复核。
- 发展：季长青先核对他过去记录，再让他连续两次输入灵力，排除临时服药爆发。
- 转折：炼气四层结果稳定成立，周恪无法再用“境界未登记”拖延。
- 高潮：季长青在矿役名单副本上划去林砚名字，并要求籍录房当日同步正式记录。
- 结尾：林砚走出考功院时，问果出现简短提示：【已推翻已确认结局：黑石矿役。命数+1。新命岔已生成。】

#### 情节安排（多线）
- 主线推进：L01 第一次从被动岗位中脱身。
- 辅线推进：L03 周恪操作链第一次暴露为“需要被解释的流程异常”；L02 修为四层正式成为公开资产。
- 事件线 / 任务线：矿役撤名完成。
- 任务卡点：复核真伪 → 稳定显示四层 → 程序必须改名单。
- 感情线 / 关系线：季长青对林砚从“异常申请者”变成“值得记一笔但仍需验证的人”。
- 逻辑线：可验证结果 → 触发明文规则 → 名单撤销 → 原未来结局不再成立 → 问果结算命数。

#### 人物关系和出场顺序
- 出场顺序：林砚 → 季长青 → 周恪（后到/被叫来确认手续）→ 少量旁观弟子。
- 镜头准入：季长青负责审核，林砚负责主动提出诉求；周恪只争程序解释，不抢主角镜头。
- 人物关系变化：季长青对林砚由陌生转为有限注意；周恪确认林砚已成为自己账链上的风险点。
- 视角/信息差：所有人知道四层是真的；只有林砚和读者知道它来自未来结果。
- 信息差触发点：周恪判断“突然四层也只是运气”，读者知道问果还有第二次使用可能。
