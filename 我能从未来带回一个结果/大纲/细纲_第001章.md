# 细纲（第1章）

### 第一章：我的未来，死在二十七天后
- 核心事件：林砚发现自己被提前写入黑石矿役名单，第一次开启问果，在九十日未来里看到自己死于矿难，并把“炼气四层”这个结果带回现实。
- 字数目标：3200字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期第1章；立处境、立主角目标、立金手指基点。
- 单元ID/位置：U01｜矿役改命，第1拍“坏结果已写在纸上”。
- 目标情绪：被一张名单堵死退路的窒息 → 看见未来后的惊惧 → 发现自己可以把一个结果带回来的强期待。
- 主角目标/关键选择：先确认矿役名单是否真实、是否还有正常退出路径；推演结束后在多个收益中选择“炼气四层”。
- 章节定位：高压 / 金手指首秀。
- 本章结构公式：名单落锤 + 规则核实 + 第一次未来 + 只取一果。
- 章首钩子：结果式危机——林砚在自己经手的矿役调令上看见了自己的名字，生效只剩三日。
- 爽点：章末“未来炼气四层”直接成为现实结果，但只写到结果落身与可验证变化，不提前写复核清算。
- 本章标价：①黑石矿月例5灵石但高损耗；②林砚每月需寄约0.5灵石药钱，失去宗门正常岗位意味着妹妹药钱不稳。两把尺子在问果前立好。
- 闭环状态：本章完成“获得未来信息 → 选择结果”；现实制度兑现放第2-3章。
- 本章禁止提前释放：不解释问果来源；不出现司命；不揭周恪完整寻租链；不让林砚知道名单幕后原因；不写名字已撤销。
- 写手自由区：籍录房纸墨/竹简/玉牌细节、林砚核对流程的具体动作、未来矿区关键场面的呈现方式、系统提示排版。
- 契约风险：契约安全。第一次关键选择必须由林砚自行比较结果价值后作出。

#### 内容概括（五段式）
- 起因：林砚整理黑石矿役调令时看到自己的名字，且顺位比正常轮转提前。
- 发展：他核对公示期限、修为豁免和自己的资源，确认靠三日内正常修炼从炼气二层冲到四层几乎不可能。
- 转折：问果开启，他进入从当前时点延伸的九十日未来。
- 高潮：未来里林砚被送进黑石矿，在矿中靠一次机缘修到炼气四层，却在第二十七日死于坍塌与地底妖虫混乱；结算时出现数个可取结果。
- 结尾：林砚放弃灵石和模糊矿区情报，只选【结果：炼气四层】，现实中的灵力周天当场越过两层门槛。

#### 情节安排（多线）
- 主线推进：L01 从“被安排”推进到“出现改命工具”。
- 辅线推进：L02 建立炼气四层免矿役的资格尺子；L05 用寄药钱说明矿役风险不是抽象数字。
- 事件线 / 任务线：矿役调令三日后生效。
- 任务卡点：要撤名单 → 卡在修为不足 → 问果给出未来可达结果 → 选择四层作为破口。
- 感情线 / 关系线：无显性感情线；通过妹妹来信/寄钱习惯建立亲情锚点即可，不展开煽情回忆。
- 逻辑线：名单提前 → 正常退出条件是炼气四层 → 现实做不到 → 问果未来做到过 → 带回四层。

#### 人物关系和出场顺序
- 出场顺序：林砚 → 唐槐（短场）→ 矿役调令/问果。
- 镜头准入：唐槐只负责给“这名单时间不对”的正常人参照；问果不人格化讲话。
- 人物关系变化：林砚与唐槐无大变化；林砚与自身命运从被动接受转为第一次出现主动变量。
- 视角/信息差：读者与林砚同步知道名单和问果；都不知道谁动了名单。
- 信息差触发点：无。
