# 细纲（第5章）

### 第五章：我先拿走证据
- 核心事件：林砚放弃更直观的修为收益，选择带回“私账丙页完整记忆”，并利用籍录房正常权限抢在周恪销毁证据前锁定原始记录链。
- 字数目标：3000字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期第5章；第一次明确证明“低表面价值结果”能撬出更大现实收益。
- 单元ID/位置：U01，第5拍“从预知转为主动布置”。
- 目标情绪：选择犹豫 → 主角做出非直观决策 → 先手拿证据的智性爽感。
- 主角目标/关键选择：选择私账记忆；不直接偷私账，而是先用记忆中的调令编号去核对宗门正式回执，构造合法、可验证的证据链。
- 章节定位：推进 / 信息反制。
- 本章结构公式：结果选择 + 记忆落地 + 编号核对 + 实物锁定。
- 章首钩子：三项结果里，最不像“外挂奖励”的那一项，被林砚选了。
- 爽点：他用未来记忆提前一步找到周恪尚未来得及清理的原始编号与夹层私账，不靠赌、不靠搜魂。
- 本章标价：炼气四层稳固只是减少后续修炼时间；一页账能直接解除停职/栽赃后患并让周恪失去权限，杠杆更高。
- 闭环状态：完成“选择记忆结果 → 现实取证”；正式提交和清算留第6章。
- 本章禁止提前释放：不当场抓周恪；不让唐槐替主角拿证据；不让季长青提前知道全部；不升级问果权限。
- 写手自由区：林砚如何从一串账页数字反推实物位置、籍录房档案柜细节、一次性同事反应。
- 契约风险：契约安全。选择和取证均由林砚完成，唐槐最多做见证人。

#### 内容概括（五段式）
- 起因：问果结算，林砚选择完整记住私账丙页。
- 发展：记忆不是“知道周恪有账”这么粗，而是保留那页的调令编号、灵石数额、三个名字与藏放位置。
- 转折：林砚没有直接去翻周恪私物，而是先在自己有权限接触的正式回执中找对应编号，发现三份调令的实际公示时间与账页记忆吻合异常。
- 高潮：利用自己整理旧档的职责，他在周恪尚未来得及清理前找到夹在废弃回执册背板内的私账原页，并让唐槐只负责在场见证“从哪里取出”。
- 结尾：林砚把私账、三份正式回执和自己的矿役调令复本封在同一只档袋里，准备直接去考功院。

#### 情节安排（多线）
- 主线推进：L01 林砚第一次用结果杠杆主动改变下一段未来。
- 辅线推进：L03 证据链完整；L02 主动放弃短期修为收益，强化资源选择逻辑。
- 事件线 / 任务线：在周恪未来焚账之前完成取证。
- 任务卡点：私账是私人违法记录，单独拿到可能被说成伪造 → 必须与正式调令编号互相印证。
- 感情线 / 关系线：唐槐从“同事”向“可做可信见证的人”推进一步，但不承担关键判断。
- 逻辑线：未来记忆 → 正式编号核对 → 找到可验证异常 → 定位实物 → 证据链闭合。

#### 人物关系和出场顺序
- 出场顺序：林砚 → 唐槐 → 周恪（远处/短接触）。
- 镜头准入：唐槐台词只围绕档案和“这东西你最好别在这里打开”；周恪不与林砚正面对峙，维持时间压力。
- 人物关系变化：唐槐意识到林砚不是撞大运，而是在有计划地处理后患。
- 视角/信息差：林砚知道周恪未来会焚账；周恪以为实物仍安全。
- 信息差触发点：周恪从档房门口经过时，林砚已经把档袋封好，但对方不知道里面是什么。
