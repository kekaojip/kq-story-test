# 第一卷《名单之外》卷纲

## 核心信息
- 章节范围：第1-50章
- 字数目标：约15万字
- 本卷定位：开篇期完整卷；建立主角、问果第一层、青衡宗外门资源逻辑与第一次身份抬升
- 起始状态：林砚炼气二层末段、籍录房低层弟子、被提前列入黑石矿役名单
- 结束状态：林砚炼气六层左右、取得内门候补观察资格、掌握问果第一层稳定用法，并第一次留下“命线无法稳定记录”的异常

## 卷契约与终局储备
- 卷契约：读者每隔一个短周期都能看到“未来先跑一次 → 林砚只选一个结果 → 现实规则被结果撬动”的完整闭环；本卷重点证明选择比单纯刷修为更重要。
- 本卷主推线：身份线。从“可被随手塞进矿役名单的外门底层”抬到“考功院正式记录的内门候补”。
- 本卷战果：修为线炼气二→六；资源线从月例紧缺到能自主选择功法/任务；关系线建立唐槐、季长青、孟无咎三类长期关系；信息线知道问果同锚点不可重开、命数需主动改命获取。
- 本卷解锁的终局里程碑：完整掌握问果第一层“身内之果”的使用逻辑。
- 本卷禁碰的终局底牌：司命一脉真实身份；问果多世界真相；名位之果以上权限；太一命君；任何界域级改写。
- 本卷鼓励长出的：外门可数资格、任务规矩、具体资源价格、能承接现实压力的同门与执事、不同价值类型的身内之果。
- 契约风险：契约安全。所有关键改变由林砚选择结果并亲自推动现实，配角不替他完成核心清算。

## 阶段边界
### 本卷允许释放
- 问果第一层全部基础规则。
- 身内之果：修为、单项技艺、单段记忆/认知、身体状态。
- 命数与同锚点不可重开的规则。
- 青衡宗外门制度与小考/任务资源链。

### 本卷禁止提前释放
- 问果来自真实可能世界的定论。
- 任何“司命”专名与完整组织设定。
- 名位、因果、界域类结果可直接带回的能力。
- 宗主/域级大人物因为第一卷异常直接关注主角。

# 剧情单元卡

## U01｜矿役改命（第1-6章）
- 主推线：L01 身份线。
- 战果线：L02 修为从炼气二层→四层；L03 周恪冲突完整结算；L05 药钱压力得到短期稳定。
- 单元目标：三日内撤掉矿役调令，并确认名单为何提前出现林砚的名字。
- 核心冲突：林砚没有资源、修为和上层关系，仅靠申诉无法从已公示的名单里退出。
- 对手承接：周恪。威胁来自执行权限和流程信息差，不来自高阶武力。
- 对标剧情参照：自创。理由：当前项目无对标书，按五幕因果链 + 结果型模拟核心梗自排。
- 章级推进下限：每章必须推进“矿役是否生效 / 问果规则验证 / 周恪证据链 / 林砚现实资格”至少一项。

### 单元情绪发动机
核心情绪命题：**本来只能接受名单的人，第一次把自己的名字亲手划出去。**
- 承载对象/缺口：矿役调令，象征林砚没有选择权。
- 缺口维持原因：修为只有炼气二层，名单已进入公示，正常流程对他不利。
- 本轮触发：问果让他看到九十日内死在黑石矿的未来。
- 主角不可替代点火：林砚亲自判断多个未来结果的价值，选择“炼气四层”而不是灵石或一段模糊信息。
- 意义变化：矿役名单从“命令”变成“可以被资格规则推翻的纸”。
- 可见兑现：测灵石确认炼气四层；名字被撤；周恪的寻租账链被林砚利用第二次问果锁定并交出可验证证据。
- 题材兑现：结果型模拟第一次完成“未来赢一次 → 现实搬回结果 → 规则改写”。

### 关键节拍
1. 名单公示，三日后生效。
2. 林砚确认自己按正常顺位本不应这么早入选。
3. 第一次问果：九十日未来中进入矿役、修炼、发现机会、最终死于矿难；未来里他曾达到炼气四层。
4. 林砚只取“炼气四层”。
5. 现实复核，矿役资格被硬规则撤销。
6. 周恪试图用手续拖延，林砚确认仅修为还不能保证后续安全。
7. 现实被改变，生成新命岔并结算命数。
8. 第二次问果只展开与周恪后手相关的关键未来，林砚放弃更诱人的小修为收益，带回一段“账页位置与内容”的完整记忆。
9. 现实抢先取得原始证据。
10. 考功院按证据处理周恪，林砚拿回岗位自主权与补偿，进入季度小考报名窗口。

### 结构坐标
- 1/4：第2章，炼气四层结果在现实得到第一次硬验证。
- 中点：第3章，名字正式撤出矿役名单，第一层爽点兑现。
- 3/4：第5章，第二次问果带回账页记忆，主角从“自救”转为主动反制。
- 收束：第6章，周恪权限被剥离，问果闭环完成。

### 供给自查
1. 对手戏：周恪第2-6章持续承接；季长青第3/6章提供制度审核，不抢清算。
2. 未来3章角色卡：林砚、唐槐、周恪、季长青已建。
3. 能力增量：问果第一层、炼气四层均有设定来源；不额外新增高阶术法。
4. 数字制度：矿役三日公示、炼气四层免强制矿役、灵石/贡献刻度已落 `设定/世界观/修炼与资源刻度.md`。
5. 地点：籍录房、考功院、弟子住舍均为宗门常规功能空间；正文只需补局部陈设，A级自由发明。
6. 故事线：L01/L02/L03/L05有可见推进。
- 供给单：无缺口。
- 建纲追加：无。

## U02｜外门小考（第7-18章）
- 主推线：L01 身份线。
- 战果线：L02 技艺/贡献；L04 孟无咎竞争线建立；问果展示“技艺结果比修为结果更值”的新玩法。
- 单元目标：进入小考前十，拿到功法与贡献资源，并让考功院正式把林砚列为可培养对象。
- 核心冲突：林砚修为刚到四层，硬实力和积累仍落后于长期准备小考的弟子；问果只能带回一个结果，无法把未来里的修为、剑法和经验全部搬回来。
- 对手承接：孟无咎为竞争标尺，另设两名一次性小考对手，均A级现场角色，不建长期卡。
- 对标剧情参照：自创。用“选一个结果”的机会成本制造本单元核心爽点。
- 章级推进下限：每章至少改变小考排名预期、技艺掌握、资源筹备、竞争关系之一。

### 单元情绪发动机
核心情绪命题：**别人以为外挂最值钱的用法是直接涨修为，林砚第一次用选择证明“会挑结果”才是能力核心。**
- 承载对象：季度小考排名与内门观察资格。
- 缺口：林砚境界达标但技艺薄、准备时间短。
- 受阻原因：小考并非只看修为，强行再选一次修为结果边际收益低。
- 触发：第三次问果里，他在未来分别接触更高修为、更多灵石与《折风步》小成等多个结果。
- 主角点火：林砚放弃表面最直观的“炼气五层”，选择《折风步》小成。
- 可见兑现：技艺测试与实战中，林砚用身法把已有炼气四层价值放大，排名持续上升。
- 题材兑现：只取一果产生真正决策爽点。

### 结构坐标
- 1/4：第9章，《折风步》小成在现实验证，孟无咎第一次重新估价林砚。
- 中点：第12-13章，林砚以四层修为打入前二十，证明选择有效。
- 3/4：第16章，对上更高修为选手，第一次逼出“信息选择也可能比技艺更值”的后续命题。
- 收束：第18章，进入前十并拿到资源/考功院观察记录。

### 供给自查
1. 对手戏：孟无咎第7章开始稳定承接；单场可加A级一次性对手。
2. 未来3章角色：林砚、孟无咎、季长青已建。
3. 能力库存：《折风步》与技艺五档已落设定。
4. 数字制度：报名/小考时限、前十奖励范围已落设定。
5. 地点：演武场、功法阁为宗门常规空间，正文按需A级补局部。
6. 故事线：L01/L02/L04持续推进。
- 供给单：无缺口。
- 建纲追加：第8章需引用《折风步》20贡献借阅价格，已存在，无新增。

## U03｜灵药谷任务（第19-33章）
- 主推线：L02 资源线转 L01 身份线。
- 战果线：L04 与孟无咎从竞争进入阶段合作；L05 获得更稳定药钱；问果第一次出现“带自己收益”与“带关键记忆”冲突。
- 单元目标：完成灵药谷失窃/妖兽异常任务，获得足够贡献并拿到内门候补所需实绩。
- 核心冲突：未来里存在一份能快速提升修为的个人结果，也存在一段能避免任务队伍重大损失的关键记忆；二者只能选一个。
- 对标参照：自创。
- 情绪：贪取个人收益的诱惑 → 主角判断更高杠杆信息 → 现实提前布置 → 以更小成本拿到更多实际战果。
- 本单元不得用“主角牺牲所有收益救人”做廉价道德题；选择记忆必须最终也给主角带回可见战略收益。

## U04｜内门候补（第34-50章）
- 主推线：L01 身份线最大兑现。
- 战果线：L02 炼气六层左右；L04 孟无咎竞争关系稳定；L06 命线异常只露一角。
- 单元目标：完成候补考核，进入内门观察名单。
- 核心冲突：候补考核同时看实战、任务履历、修为与判断，林砚不能靠一次结果跨过全部维度。
- 对标参照：自创。
- 大爽点：前几个单元积累的修为、技艺、证据处理能力与任务实绩在同一场考核里形成复利，而不是临时再塞一个万能结果。
- 卷尾钩子：命籍玉牌对林砚的寿元/命线记录出现短暂空白，考功院按法器故障更换；林砚记下此事，但本卷不解释。

# 人物弧线

- 唐槐：从普通同事→可信基层关系点。
- 季长青：从程序审核→把林砚列为值得继续观察的弟子。
- 孟无咎：从只按修为估价林砚→承认“选择与准备”也是实力。
- 周恪：第6章完成本卷功能并退出核心舞台。

# 本卷伏笔
1. 林砚第一次推演死亡并不意味着现实必死，只证明那条分支已发生过。
2. 问果对“结果单一性”的判定偶尔比林砚自己的语言理解更严格，为后期高阶结果判定埋规则伏笔。
3. 第45-50章命籍玉牌出现命线记录空白，仅做异常，不解释来源。

# 本卷反转规划
- 小反转：第一次问果最值钱的不是未来三枚灵石，而是炼气四层这个资格结果。
- 中反转：周恪事件里第二次问果最值钱的不是再涨一点修为，而是一段可验证账页记忆。
- 中反转：外门小考中，林砚放弃炼气五层，选《折风步》小成，靠技艺把现有境界价值放大。
- 大反转：卷末读者以为问果只是林砚个人外挂，命籍玉牌却第一次表现出“现实的命运记录也被影响”的迹象。

# 大纲安全七检
1. 本卷交付情绪：从被名单安排的窒息，到一次次用选择夺回控制；核心模式可靠。
2. 核心冲突：底层资格/资源不足 + 只能选一个结果的机会成本。
3. 节奏：1-6快反击；7-10短准备；11-18竞争升压；19-33任务扩张；34-50大考兑现。低压段控制在必要范围。
4. 伏笔：问果判定、命线异常；无上一卷待回收。
5. 章节定位：高压、推进、修炼/准备、关系回收有层次，不全程高压。
6. 阶段释放：只释放第一层问果与外门体系，终局内容全部压住。
7. 契约：安全。关键选择、行动后果与核心收益都回到林砚；无配角夺走期待所有权；升级台阶未透支。

## 降级检查
- 删除“未来结果只能取一个”后：本卷会退化成普通修仙系统升级文。结论：核心题材机制不可删除，当前各单元均围绕它设计，PASS。
- 删除林砚后：关键结果选择、现实反制与收益结算无法成立。结论：主角不可替代，PASS。

# 刻度台阶 / 打脸债 / 压力线轮转
## 刻度台阶
炼气二层→四层（U01）→四层稳定 + 技艺小成（U02）→五层及任务实绩（U03）→六层左右 + 候补资格（U04）。

## 打脸债
本卷不主打“反派轮流嘲讽”。认知差只在明确资格/排名场景兑现：矿役资格、小考排名、候补审核。

## 压力线轮转
制度生存压力（U01）→竞争压力（U02）→外勤风险与选择压力（U03）→综合资格压力（U04），避免连续同一种对手/胜负手。
