# 细纲（第4章）

### 第四章：第二次未来
- 核心事件：林砚在矿役撤名后的新现实上进行第二次问果，看见周恪会借“篡改名册/失窃回执”把责任重新压回他头上，并发现一页能证明寻租链的私账。
- 字数目标：3000字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期第4章；从“金手指保命”升级为“金手指辅助主动反制”。
- 单元ID/位置：U01，第4拍“新未来暴露后手”。
- 目标情绪：刚松一口气 → 发现坏结果会换形态追来 → 主角开始主动算下一步。
- 主角目标/关键选择：用第二次问果确认撤名后最大的真实后患；面对多个可选结果，暂不急着做决定直到看清账页价值。
- 章节定位：推进 / 推演 / 信息战。
- 本章结构公式：现实确认余波 + 第二次推演 + 周恪后手 + 私账出现。
- 章首钩子：矿役调令已经没了林砚的名字，但他知道问果既然给了新命岔，就说明“活下来”不是故事结束。
- 爽点：第二次未来里，林砚不再只是受害者，他主动跟踪流程变化并摸到周恪真正软肋。
- 本章标价：修为再涨一点的边际价值 < 能彻底解决周恪后患的证据记忆；本章先把这个价值差摆出来。
- 闭环状态：完成第二次未来信息获取，结果选择留到章末/第5章开头完成。
- 本章禁止提前释放：不让周恪现实中直接栽赃成功；不把私账实物拿到手；不清算周恪；不新增高阶问果规则。
- 写手自由区：未来时间压缩方式、周恪后手的具体流程细节、私账页在未来出现时的视觉锚点。
- 契约风险：契约安全。林砚主动用新命数看未来，并自己识别真正高杠杆信息。

#### 内容概括（五段式）
- 起因：撤名后，林砚回到籍录房，发现周恪表面恢复正常，但把几份旧回执单独收走。
- 发展：林砚判断继续等对方出手太被动，消耗新命数开启第二次问果。
- 转折：未来数日里，周恪以“名册被人为改动”为由启动内部核查，并让一份关键回执失踪；林砚因无法证明自己没有动过原件而被停职调查。
- 高潮：未来里的林砚最终发现周恪在焚毁一页私账，上面记录了几名弟子的灵石数额、对应顺位和调令编号。
- 结尾：问果结算出现“炼气四层稳固”“一段《青衡引气诀》体悟”“完整记得私账丙页内容”等结果，林砚盯住最后一项。

#### 情节安排（多线）
- 主线推进：L01 从逃离坏结果转为主动设计现实。
- 辅线推进：L03 周恪寻租链从推测变成未来可见事实；L02 暂不推进境界，突出机会成本。
- 事件线 / 任务线：未来内部核查将成为新的坏结局。
- 任务卡点：周恪的权力在流程内 → 单靠四层修为解决不了 → 未来给出可验证私账入口。
- 感情线 / 关系线：唐槐只在现实开头体现籍录房气氛变化，不进入推演核心。
- 逻辑线：撤名伤到周恪利益 → 周恪未来反扑 → 林砚在未来失败一次 → 失败中发现真实证据 → 结果选择出现。

#### 人物关系和出场顺序
- 出场顺序：林砚 → 周恪（现实短场）→ 问果未来中的周恪/季长青/唐槐。
- 镜头准入：未来中的配角都服务于“林砚为什么会输、证据在哪”。
- 人物关系变化：林砚对周恪从“怀疑有问题”升级到“确认其在利用权限获利”。
- 视角/信息差：林砚与读者知道未来私账；现实周恪不知道自己的藏账位置已暴露。
- 信息差触发点：章末形成明确优势。
