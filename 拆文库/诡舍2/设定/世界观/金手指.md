# 金不换的核心能力与“金手指”边界

## 1. 污染视觉

- 灵异污染接近时，金不换视野会出现不同程度的红色。
- 可用于风险预警和粗略强度判断。
- 不是绝对检测器：拥有意识、会隐藏的荒诞可以绕过，和春天台事件已明确证明。

## 2. 韩昭雪契约 / 粉色笔记

- 核心能力表现为“约束”：通过黑色丝线将灵异相关目标拖入笔记中的别墅空间。
- 不能理解成永久秒杀/无限收纳。
- 对方越强，拖入越困难，约束持续越短，韩昭雪消耗越大。
- 使用后存在明显真空/恢复期。
- 红漆箱甚至能让韩昭雪产生本能畏惧，并一度让笔记世界失联。

## 3. 真正的主角优势

当前文本最稳定的“金手指”其实是人物能力组合：

**高死亡耐受 + 观察力 + 可证伪思维 + 风险管理 + 有限制的灵异工具。**

如果只复制笔记能力而丢掉前四项，人物爽感会大幅下降。
