# 节奏：当前66章权威索引

> 本文件是下游写作读取的节奏/关键信息推进权威来源。

## 一、宏观节奏

整体采用：

**强开篇5章 → 大单元19章 → 2章主线过渡 → 大单元24章 → 4章组织/日常缓冲 → 下一大单元12章+（进行中）**

长单元之间必须有短缓冲。缓冲不是空水文，而承担三件事：兑现上一单元收益、推进长线谜团、让人物关系恢复人味。

## 二、单元内部的核心节拍

### 节拍A：规则确定性破坏

1. 给一个读者能理解的暂时规则。
2. 主角成功使用一次，建立信任。
3. 给一个历史/对比基线。
4. 出现很小但硬核的违例。
5. 主角先验证，不直接下结论。
6. 危险实体坐实违例。
7. 更新行动策略。

情绪：安全感 → 微疑 → 不安 → 确认危险 → 理性恢复。

### 节拍B：证据改写模型

1. 当前解释A能解释多数事实。
2. 新证据只与A的一小部分冲突。
3. 主角主动寻找第二证据或设计测试。
4. A被推翻/收窄成B。
5. 旧章节中的细节因此获得新含义。
6. B直接导出下一步行动。

这是姐姐妹妹、蝗儿沟、和春都在复用的核心节拍，只是被验证的对象不同。

### 节拍C：聪明主角的可信化

禁止直接写“他已经看穿”。当前样本常用：

**先保留怀疑 → 故意说错/说假/借东西/改变路径 → 观察对方会不会出现只有假身份才会有的反应 → 行动抓人 → 事后再公开证据链。**

这能同时保留悬念和公平性。

## 四、高潮与缓冲

- 小高潮不依赖打斗，可由“一个事实推翻整个解释”承担。
- 中高潮通常是模型确认后立刻行动，如抓假汪睿、找到红箱。
- 大高潮才组合灵异能力/多人协作/情绪释放。
- 大高潮后必须给善后与人物日常，让读者回收安全感。

## 五、章尾钩子习惯

高频功能位：
1. 发现一个反常事实。
2. 旧答案突然不成立。
3. 新角色/新危险露出一半。
4. 主角已经想到答案但暂不说。
5. 一个更大的因果问题替代刚解决的问题。

避免机械每章都用“门后出现鬼”。钩子的对象应在规则、人物、信息源、关系模型之间轮换。

## 六、对原创项目的迁移提醒

如果用于“规则维修员”方向，最该迁移的是：

**规则不是谜题清单，而是一套可暂时相信的现实模型；真正的故事来自模型损坏、污染、互相冲突，以及主角如何验证哪一层出了问题。**

不要复刻本书的荒诞名称、怨界、红箱、具体场景或人物关系。
