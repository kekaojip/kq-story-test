# 剧情单元：姐姐妹妹

- 章节：6-24
- 类型：怨界/家庭悬疑单元
- 核心功能：展示关系型推理，并把单元收益转成长期能力与主线目标

## 单元大纲

### 建立（6-10）
- 用一场家庭晚宴让全部核心人物同场，不给规则清单，只给异常行为。
- 妹妹、姐姐、父母、客人各自留下可回看的微证据。
- 危险首先表现为“谁的行为不正常、谁在保护谁”，而不是机关说明。

### 收窄（11-17）
- 妹妹的提示、备用钥匙、父亲出现、地下室大量客人尸体不断改写早期解释。
- 主角发现妹妹邀请外来者并非单纯害人，而是在用客人替家人承受姐姐的占有欲。
- “妹妹可能是凶手”的表层谜题逐渐退场，真正问题变成家庭关系。

### 情绪病灶（18-22）
- 妹妹笔记里“爱的人”不断减少，只剩姐姐，显示爱已异化为控制。
- 母亲与父亲的死亡方式补齐姐姐嫉妒/占有逻辑。
- 解谜目标从“找凶手”改为“让妹妹停止用逃避维持循环”。

### 释放（23-24）
- 金不换让妹妹从父亲视角重看悲剧，把恐惧改造成愤怒和行动。
- 妹妹反击姐姐形成情绪释放。
- 随后再揭一层：妹妹才是死者，姐姐可能仍活着。
- 心结被改造成“去现实里找到姐姐”，并由契约把单元结果带入长篇主线。

## 单元写法公式

**异常群像 → 行为证据 → 解释模型A → 新证据推翻A → 解释模型B → 找到情绪病灶 → 改变人物行为 → 表层释放 → 最终身份反转 → 把谜底转成长期任务。**

## 核心优势

这个单元没有靠每章塞一条新规则撑长度。它靠“同一件事随着新证据出现不断换含义”维持追读，因此信息具有复利效应。
