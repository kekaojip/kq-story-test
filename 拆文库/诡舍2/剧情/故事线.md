# 故事线：当前 66 章

## 1. B区异常蔓延主线

公交站荒诞异常 → 小区多处旧规则失效 → 烛山确认多点同时蔓延 → 蝗儿沟出现高复杂污染 → 和春小区四只荒诞同时蔓延且蓄水池鬼异常强化。

当前未解：谁或什么在推动B区大规模同步异常。

## 2. 金不换生存/成长线

普通但异常稳定的观察者 → 契约韩昭雪获得“约束” → 学习火虫体系 → 进入烛山 → 用实际荒诞处理积累能力与组织位置。

成长重点并非境界数字，而是：观察模型、可证伪测试、灵异工具组合、对不同层级危险的风险管理。

## 3. 韩昭雪 / 韩昭虹线

韩昭雪怨界 → 金不换发现妹妹才是死者 → 七天内寻找现实中的姐姐 → 查到年轻韩昭虹是烛山二级火虫 → 韩昭虹进入和春小区后失联。

这条线把首个副本成果持续绑定到当前主线。

## 4. 李清欢 / 良言 / D区线

李清欢是来自D区的“媒”，受良言指引找到金不换；她寿命受限，跟在金不换身边能延长存活，但具体原因未揭晓。金不换也在查良言，两个谜团同名汇合。

## 5. 红漆箱线

蝗儿沟村长期祭祀红箱 → 内村存在试图借外界力量取得 → 金不换将箱子收入韩昭雪笔记 → 一枚锁扣曾被打开并泄出足以压制韩昭雪的怨气 → 李清欢将其封入地下室。

箱子不是已解决战利品，而是随身携带的长期灾难资产。

## 6. 血门梦境线

金不换此前长期在血门梦境中反复面对死亡，这解释了其异常心理稳定性。当前 66 章尚未揭明血门梦、良言、李清欢、B区同步异变之间是否存在联系。

## 7. 当前和春“阿爸”线

潘玥儿、重伤矮小男人反复出现“阿爸”关键词；蓄水池鬼异常强度及其污染来源仍未知。样本在此处中断，不能提前闭环。
