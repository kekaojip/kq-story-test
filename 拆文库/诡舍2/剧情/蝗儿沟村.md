# 剧情单元：蝗儿沟村

- 章节：27-50
- 类型：现实封闭村落 / 信息源悬疑

## 单元大纲

### 被迫入局（27-34）
- 山体滑坡、货运时效、车辆失控层层关闭正常退路，使主角不是“没事找鬼”。
- 村庄历史通过司机三次到访建立异常基线。
- 唯一亮灯、官方广播、显眼账本都看似提供帮助，但都被保留为待验证信息。
- 光源最终反转成捕猎装置，大量村民怪化。

### 合作与显性谜核（35-38）
- 汪睿、唐玉凤加入，箱子、祭祀、内外村等信息拼成首个解释模型。
- “箱子被打开了”看似是灾难原因。
- 村长信件给出两个谜语位置。

### 真假同伴（39-46）
- 金不换不等证据自动出现，而是主动制造测试：信件温度、故意叫错男友名字、借手机、假箱子位置。
- 假汪睿、假徐杨依次暴露。
- 最大反转来自一个物理事实：红箱的锁一直完好，所以“箱子被打开”本身就是诱导信息。
- 敌人由“箱中物”切换为能夺取/附身影子的内村存在。

### 多方收束（47-50）
- 笔记、韩昭雪、李清欢、徐杨、汪睿、老佟、王贯各有功能，不由主角单人开挂解决全部问题。
- 红箱泄露更高层恐怖，把单元胜利变成长期负债。
- 女鬼被解决、村民恢复、唐玉凤获救，给单元完整回收。

## 单元写法公式

**被迫进入 → 建立“可信信息” → 主角保留怀疑 → 设计可证伪测试 → 同伴/线索反转 → 一个硬事实推翻整个旧模型 → 能力对抗 → 团队收束 → 留一个更危险资产进入主线。**

## 最值得迁移的技巧

“聪明主角”不是等作者告诉他答案，而是主动设计会产生不同结果的测试。如果对方是真的会怎样、如果是假的会怎样，然后让行为结果替作者证明。
