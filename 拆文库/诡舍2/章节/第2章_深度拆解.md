# 第2章《有什么「东西」正在影响它们》深度拆解

- 字数约：1712 字符（去空白）
- 核心事件：金不换复盘公交站异常，判断其可能正在蔓延；随后通过与苏炜仪的电话，把危险从单个站台扩展为B区多地荒诞同步异常，并提出“有某个更强东西正在影响它们”的长线威胁。

## 开篇钩子

- 类型：承接型悬念 + 信息差
- 手法：第一段不是庆祝脱险，而是立刻拿“三个月经过九次”与今晚表现做对比，告诉读者刚才那只鬼其实比过去更危险。
- 效果：强。上一章的小胜立刻被改写为“异常样本”，读者注意力从“主角会不会死”升级到“为什么规则正在变化”。

## 人物出场 / 深化

- 金不换：从“胆大”进一步转成“会复盘、会报告、会考虑普通住户风险”的行动型人物。
- 苏炜仪：从电话信息源升级为可信赖的长期关系角色。救命之恩解释了他为什么愿意帮金不换查资料、提醒风险。
- 廖组长：只被提及，作为烛山组织层级存在。

### 主角深化

这一章补上两层安全感：
1. 他不是只顾自己脱险，会想到附近居民可能成为第一批受害者。
2. 他不是“凭感觉逞强”，会把异常上报组织，并根据已有经验估计风险。

## 世界观铺设

- A/B/C/D 四区安全梯度。
- B、C区是大多数普通人的生活区。
- 荒诞通常有严格规则与活动区域。
- 「蔓延」意味着规则/范围/攻击性可能恶化。
- 「烛山」是治理荒诞的官方性质组织，在B/C区设置哨站。
- 存在「契约荒诞」概念，但金不换当前没有。

### 铺设方式

本章信息量明显高于第一章，但大部分设定都挂在一个即时问题上：刚才那只荒诞为什么反常，以及现在该怎么办。因此说明段虽然集中，却不是完全脱离剧情的百科。

## 结构拆解

| 段落范围 | 功能 | 约字数 | 作用 |
|---|---|---:|---|
| 脱离站台后复盘 | 异常确认 | 300 | 用历史对照证明“今晚规则正在变” |
| 四区 + 荒诞稳定规则 | 世界观扩张 | 470 | 从单个公交站扩成社会运行框架 |
| 联系烛山 | 行动推进 | 240 | 主角把观察转为现实行动 |
| 苏炜仪救命关系回溯 | 关系/可信度 | 300 | 解释信息源与关心的合理性 |
| 多地同步蔓延推断 | 主线升级 | 400 | 把局部事件升级成B区级未知源头 |

## 爽点 / 情绪机制

本章传统爽点很弱，主要承担“认知升级”和“可靠感强化”。

- 情绪流：刚脱险 → 发现刚才并不正常 → 世界范围扩大 → 组织也人手紧张 → 老经验者给出更坏的判断。
- 释放形式：不是击败敌人，而是主角迅速从现象中识别异常，并采取正确动作。
- 风险：如果连续多章都这样“解释 + 电话”，会削弱现场感。因此第三章必须重新把危险落到场景里，原文确实这么做了。

## 抽象对抗型路由

- 核心对抗面：不再是单只荒诞，而是“多地荒诞同步蔓延”这一系统性异常。
- 紧迫感来源：烛山人手大量外出、主角没有契约荒诞、附近仍有居民、异常可能很快波及B-4区。
- 升级机制：单点攻击性增强 → 活动范围扩大 → 多点同时蔓延 → 推测背后存在更强污染源。
- 叙事替代：用经验对照、组织情报和苏炜仪的职业判断，替代传统反派现身。

## 背景信息揭示

苏炜仪半年前在C区的队伍遭遇蔓延，十五人只有三人活下来，金不换恰巧救过他。叙事功能有三重：
1. 证明“蔓延”的高死亡率不是口头吓人。
2. 证明金不换过去已有危险处理能力。
3. 给苏炜仪持续帮助主角建立关系因果。

## 章尾钩子

- 类型：宏观悬念 / 未知源头
- 内容：苏炜仪基于十七年工作经验判断，B区可能存在某个正在影响大量荒诞的「东西」。
- 期待度：强。
- 原因：它重新定义了前两章全部异常，把一只公交站鬼背后接上更高层威胁，并明确这个问题大概率会波及主角所在区域。

## 可借鉴要素

1. **小怪异常不是单独事件，而是更大问题的“传感器”。**
2. **用历史基线制造异常。** “三个月九次都正常，今晚不正常”比“今晚很可怕”更有说服力。
3. **世界观说明绑定决策。** 讲A-D区、哨站、契约，不是为了介绍设定，而是为了回答“该去哪、谁能处理、主角为什么危险”。
4. **给信息源建立关系成本。** 苏炜仪不是万能NPC，他欠主角救命之恩，因此帮助有逻辑。
5. **章尾把尺度放大。** 第一章解决一个局部问题，第二章告诉读者这个问题只是表面。
