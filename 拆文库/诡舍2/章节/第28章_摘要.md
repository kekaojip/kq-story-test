# 第28章《蝗儿沟村（2）》摘要

**概要**：暴雨和山体滑坡封死替代路线，佟司机为运送稀土不得不考虑穿越蝗儿沟；官方广播又确认村落出现灵异污染，人物被逼入风险路线。

## 关键事件 / 情节点
1. 天气先制造交通压力。 2. 正常路线不可用。 3. 替代路线也被山体滑坡封锁。 4. 货物时效增加现实成本。 5. 蝗儿沟成为剩余路线。 6. 主角并非主动找鬼。 7. 广播确认当地灵异污染。 8. 风险从猜测变成公开警告。 9. 两人仍必须权衡前进。 10. 章尾把“不得不去”坐实。

## 写法公式
现实阻碍 → 方案递减 → 最危险路线浮出 → 官方预警 → 被迫进入。核心技巧：让人物有现实理由进入恐怖地点。
