# 第11章《姐姐妹妹（6）》摘要

**概要**：金不换推断妹妹既然主动邀请他们就不太可能是当前杀手，并利用“凶手可能有备用钥匙”选择关门但不留在原房间，把此前随口询问钥匙备份变成生存伏笔。

## 关键事件 / 情节点
1. 妹妹动机被重新判断。 2. “关门”不被字面执行到底。 3. 备用钥匙风险被召回。 4. 早先询问形成回扣。 5. 原房间被判定不安全。 6. 主角把提示拆成“拖延”而非“绝对庇护”。 7. 二人准备转移。 8. 不与凶手直接碰撞。 9. 规则理解从听话升级为解释意图。 10. 章尾进入追逐/躲藏。

## 关键信息与扩写技法
- **技法**：伏笔回收 + 指令语义二次解释。

## 逐章写法公式
提示 → 字面方案 → 发现漏洞 → 回扣旧细节 → 改良方案。
