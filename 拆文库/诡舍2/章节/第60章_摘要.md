# 第60章《阿爸（6）》摘要

**概要**：金不换通过门未锁、脚步声缺失推断惨叫男性向楼上逃，追到天台找到持枪“幸存者”；对方实为跳楼鬼制造的猎物伪装，诱导金不换走向楼边，李清欢及时踹飞救下他。

## 关键事件 / 情节点
1. 死者被判断为女性。 2. 男性惨叫说明至少还有第二人。 3. 未关厕所门支持“男人曾查看”的推测。 4. 下楼脚步未被听见。 5. 主角据重力和声响判断对方向上逃。 6. 搜到天台发现持枪幸存者。 7. 权限卡暂时换来对方放下枪。 8. 笑容和靠近方式逐渐不自然。 9. 金不换发现身体其实被对方控制走向楼边。 10. 李清欢一脚踹飞跳楼鬼，救下几乎坠楼的金不换。

## 写法公式
细节追踪 → 找到“答案” → 答案主动靠近 → 认知翻转 → 临死救场。
