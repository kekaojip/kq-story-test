# 题材定位

## 基本信息
- 题材类型：悬疑脑洞 / 规则异常 / 都市异能
- 目标平台：番茄男频
- 核心梗：别人只能遵守规则活下去，林砚能看见“规则冲突”，但只有完成验证后才能做有限、临时的修补。
- 微创新点：不把规则当谜题清单，而把现实视为会出现版本冲突、回滚失败和兼容错误的运行系统；主角是“维修者”，不是万能改写者。

## 读者契约
- 核心读者承诺：看一个冷静可靠、会验证而不是瞎猜的主角，在越来越不可信的城市规则中一步步定位故障、修复危机，并从局部故障追到全城异常源头。
- 主角代理权承诺：关键模型、验证方案、修补选择和风险承担必须由林砚完成或主导；配角可以提供信息、执行动作，但不能替他完成核心判断与结算。
- 利益安全线：林砚的“差分视野/补丁权限”不能被组织无交换接管；若合作，必须换回权限、资源、保护、调查权或更高访问级别。
- 期待债：前3章兑现“看见规则冲突 + 第一次成功补丁”；前10章兑现“补丁会错/会反噬 + 城市存在同步故障”；第一卷末兑现“主角获得正式维修权限并确认妹妹失踪案与当前故障同源”。
- 题材边界：个人主导型悬疑成长。组织是资源接口、约束和舞台，不是替主角解决问题的接管者。

## 终局底牌与升级台阶
- 终局底牌：头号宿敌=“根规则维护者”的真实身份·第5卷后；终极真相=现实协议并非天然规则而是灾后人为重建系统·第6卷；金手指上限=根级写权限·最终卷；身份终点=城市级/根规则维修权限持有者·最终卷；妹妹林晚最终状态与失踪真相·第5-6卷。
- 升级台阶：权限共8档：只读 → 标记冲突 → 临时补丁 → 局部回滚 → 兼容修复 → 跨域合并 → 版本分支 → 根级写入。每档约12-18万字，支撑120万字级长篇。
- 地图/故障层级：单栋建筑 → 街区 → 城区 → 跨城区故障链 → 城市主协议 → 外城/旧协议区 → 根协议区。
- 透支红线：前期不得直接解释根规则来源；不得让主角跳过验证随意改写；不得提前确认林晚生死；不得让组织拿走补丁权限后替主角推进主线。

## 核心梗三分法
- 表层卖点：主角能看见规则哪里“坏了”。
- 深层爽点：危险越混乱，主角越能用观察、试验和有限权限把局面重新变得可控。
- 长线钩子：为什么整座城市原本稳定的规则开始同步发生版本冲突？三年前林晚失踪的“白名单事故”是否就是第一场大规模故障？
