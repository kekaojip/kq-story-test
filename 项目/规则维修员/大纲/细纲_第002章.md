# 第002章：电梯确实停过

- 单元ID/位置：U1·验证1
- 章节定位：高压推进 / 黄金三章2
- 字数目标：2800-3200 visible_chars_v1
- 主角目标：确认“六楼存在”和“本次运行不经过六楼”哪一条更接近真实。
- 关键选择：让电梯空载重复同一路线，并同时记录机械行程、门磁、监控、楼层播报四套数据。
- 行动成本：必须留一个人在轿厢内作为活体观察样本，林砚自己承担。
- 收益归属：林砚建立第一个可证伪模型：不是显示器坏，而是不同规则层在记录不同现实。
- 契约风险：契约安全。
- 可释放：异常视觉只在信息互相冲突时出现；林砚仍不能判断哪条规则“正确”。
- 禁止提前释放：补丁能力完整规则、组织体系。

## 内容概括
电梯门打开后并不是六楼走廊，而是一片贴着旧瓷砖、没有照明的狭窄平台。林砚没有出去，立刻关门并用维修钥匙锁死外门。他把住户送到安全层后，主动做空载重复实验。结果四套数据出现分裂：监控显示六楼开门，门磁显示没开，机械行程只走了五层，播报却稳定说“六楼到了”。

## 情节安排
1. 开门后的异常平台只给一眼，不探索，避免第一章就开地图。
2. 林砚先把人送走，体现可靠而非好奇压过救人。
3. 他重跑电梯，记录四组数据。
4. 第一次实验得到冲突结果。
5. 他故意断开楼层显示器，排除电子显示故障。
6. 第二次运行仍出现播报，说明“六楼”不是由普通控制器决定。
7. 林砚发现异常红线会随着验证增加变得更清晰。
8. 章尾：控制板多出一行只有他能看见的灰字——`冲突已确认：可申请临时修补`。

## 结尾设定/钩子
林砚第一次看见“临时修补”四个字，但下一行紧跟着：`错误修补将产生回滚债。`
