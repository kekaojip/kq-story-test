# 选题决策：番茄男频

- 扫榜日期：20260909
- 数据来源：长篇网文扫榜报告_番茄男频_20260909.md + 番茄官方男频阅读榜 / 新书榜公开页面
- 作者条件：无既有素材；限制仅为男频；按番茄常规长篇规划
- 决策说明：本轮没有对每个具体方向完成 >=15 本的全量结构化采集，因此所有方向可行性最高只评“中”，先拆文验证再开书。

## 推荐选题

### 选题 1：诡异副本里的“规则维修员”

- 题材组合：悬疑脑洞 + 诡异规则 + 特殊身份 + 权限成长
- 目标读者：喜欢规则怪谈、诡异副本、烧脑生存，但又希望主角拥有主动破局能力的番茄男频读者
- 核心卖点：别人只能遵守规则活下去，主角却能看见“哪条规则坏了”，并在有限权限内修补、替换或暂时关闭规则；每次改动都会带来新的代价和更高层级的审查
- 能爆的原因：当前悬疑脑洞新书榜存在强头部样本，且“特殊身份 + 明确规则 + 开局外部压力”在多个方向重复出现。该方向把常见的“玩家破解规则”换成“主角负责维护规则系统”，首屏就能形成身份反差和解释权优势。（假设，待拆文验证）
- 市场验证：悬疑脑洞新书存在百万级在读强样本，同榜也出现 APP、特殊身份、副本机制等不同变体；说明读者接受的不是唯一模板，而是清晰规则下的新切口。当前未完成同方向 >=15 本结构化采样。
- 差异化定位：不做普通闯关玩家，也不做无条件改规则的无敌挂。主角的优势是“理解并维护规则”，每次修补必须承担代价，让能力同时制造剧情。
- 可行性：中 — 市场信号强、首屏卖点清楚、无需大量现实专业素材；但样本量未达高置信阈值，且规则设计对持续创意要求高。
- 失败风险：副本只剩谜题，没有人物关系和情绪；规则越来越复杂，读者需要记说明书；主角权限过强导致紧张感消失。
- 验证动作：先用 story-long-analyze 拆 2-3 本当前悬疑脑洞强样本，重点验证黄金三章的规则揭示速度、第一次反转位置、单副本篇幅和章尾债；随后只做前 3 章方案，检查“规则是否一眼懂、主角优势是否一眼懂、第一场困境是否够急”。
- 篇幅/平台：番茄男频；建议按 100-150 万字容量设计，先锁前 25-30 万字主线，不把总字数写死。

### 选题 2：修仙世界里，所有功法都有隐藏副作用

- 题材组合：玄幻脑洞 + 修仙 + 规则金手指 + 宗门成长
- 目标读者：喜欢修仙升级、宗门竞争、功法体系，同时又需要强脑洞金手指的番茄男频读者
- 核心卖点：别人拿到神功只看品阶，主角能直接看见功法真正的“隐藏代价、错误条件和最优解”；他不是凭空获得修为，而是靠看懂规则，把别人避之不及的残功、邪功、冲突功法变成自己的成长路线
- 能爆的原因：玄幻脑洞 / 修仙方向仍有成熟大盘，而当前新书信号明显偏向“轮回、阵营选择、游戏化规则、异常机制”等一眼可懂的规则型开局。把“修仙升级”保留为长期骨架，再给一个可反复制造冲突的规则能力，兼顾熟悉感和新鲜感。（假设，待拆文验证）
- 市场验证：玄幻脑洞阅读榜存在百万级在读强样本，新书榜持续出现规则化修仙开局；但本轮没有完成同类 >=15 本的完整样本统计。
- 差异化定位：不做普通属性面板、签到或模拟器。金手指只提供“真相和规则”，真正变强仍要靠主角做选择、承担副作用、争资源、解决人与势力冲突。
- 可行性：中 — 修仙题材长期承载力强，素材门槛低于历史和硬科幻，规则能力也容易形成连续爽点；但若只写“看说明→破解→升级”会很快模板化。
- 失败风险：金手指变成万能答案；境界、功法、词条堆太多导致信息过载；宗门人物沦为给主角展示能力的工具人。
- 验证动作：拆 2-3 本当前玄幻脑洞 / 修仙规则化样本，重点验证前三章中“世界危机、金手指说明、第一次收益”各占多少篇幅；开书前先设计 10 个完全不同用途的功法副作用场景，若只能想出同一种破解方式则放弃。
- 篇幅/平台：番茄男频；建议按 120-160 万字容量设计，前 30 万字完成杂役/外门或小宗门阶段的完整闭环。

### 选题 3：每周被扔进一个陌生行业的职业真人秀

- 题材组合：都市脑洞 + 职业体验 + 真人秀 / 直播 + 圈层爽文
- 目标读者：喜欢现实背景、职业反差、直播围观、轻松爽感和连续新鲜场景的番茄男频读者
- 核心卖点：主角参加一档高压职业交换真人秀，每一阶段都被扔进一个完全陌生的真实行业；他获得的不是直接技能，而是能看见“这个行业真正决定胜负的隐藏规则”，于是从最外行的位置一路把业内人看傻
- 能爆的原因：当前都市脑洞新书活跃，重复出现的不是传统神豪，而是“现实圈层 + 反常规身份 + 明确机制”。职业真人秀天然提供持续换场、直播反馈、身份反差和社交冲突，适合番茄快节奏。（假设，待拆文验证）
- 市场验证：都市脑洞新书榜存在多本数十万在读头部样本，切口覆盖圈层卧底、短剧世界、真人秀系统等；说明现实场景仍能承载强脑洞，但具体职业真人秀方向样本不足。
- 差异化定位：不做纯直播打脸，也不让系统直接发满级技能。每个职业都有一条“外行不知道、内行靠它吃饭”的核心规则，主角需要实际解决问题才能兑现优势。
- 可行性：中 — 首屏容易理解，场景可连续更新，且不依赖大世界观；但每个行业都需要一定资料调研，长期写作成本高于表面看起来。
- 失败风险：职业只是皮，最后每个单元都变成同一种装逼；行业细节失真导致出戏；直播弹幕喧宾夺主。
- 验证动作：先挑 3 个反差最大的职业做小样本测试，每个职业只写“进入行业→第一次吃亏→看见隐藏规则→第一次翻盘”四步，如果三段读感趋同则换题；再拆当前都市脑洞强样本验证现实场景的开篇承接速度。
- 篇幅/平台：番茄男频；建议按 80-120 万字容量设计，以 5-8 万字一个职业大单元滚动推进。

## 排序结论

1. **优先验证：诡异副本里的规则维修员** — 当前新书信号最强，身份和规则都能在第一页讲清楚，最适合拿来测试 oh-story 后续拆文→开书链路。
2. **第二选择：所有功法都有隐藏副作用** — 长线最稳，修仙骨架成熟，适合验证“对标模块如何进入长期写作”。
3. **第三选择：职业真人秀** — 现实感更强、轻松度更高，但需要持续做职业资料研究，当前没有素材时运营成本最高。
